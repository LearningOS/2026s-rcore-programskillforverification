## 实验总结

本次实验在 ch5（进程管理）分支上完成了以下工作：

1. **`sys_spawn` 实现**：直接从 ELF 数据创建全新子进程（`TaskControlBlock::new`），不复制父进程地址空间。与 `fork + exec` 相比，省去了无意义的父进程内存复制开销；新进程作为当前进程的子进程加入调度队列。

2. **`sys_set_priority` 实现**：在 `TaskControlBlockInner` 中新增 `priority: isize` 字段（默认值 16，`fork` 时继承父进程优先级）；`sys_set_priority` 验证 `prio >= 2` 后写入字段并返回 `prio`，否则返回 -1。

## 简答

1. fork + exec 的一个比较大的问题是 fork 之后的内存页/文件等资源完全没有使用就废弃了，针对这一点，有什么改进策略？
   - **写时复制（Copy-on-Write, CoW）**：`fork` 后父子进程共享同一组物理页，页表项标记为只读；只有当某进程实际写入时才触发缺页异常并分配新物理页复制内容。若子进程紧接着 `exec`，则完全不会发生复制，彻底消除无效开销。
   - **`vfork`**：子进程直接借用父进程的地址空间和页表，父进程挂起等待子进程调用 `exec` 或 `exit`；子进程执行 `exec` 后才为自己建立新地址空间，父进程恢复执行。没有任何页复制，但限制子进程在 `exec`/`exit` 前不能修改内存。
   - **`spawn`（如本实验所实现）**：完全跳过 `fork`，直接从 ELF 建立全新地址空间，从根本上避免复制问题；代价是无法像 `fork` 那样在父子进程之间继承任意状态。

2. 请阅读下列代码，并分析程序的输出，假定不发生运行错误，不考虑行缓冲：

```c
int main(){
    int val = 2;

    printf("%d", 0);
    int pid = fork();
    if (pid == 0) {
        val++;
        printf("%d", val);
    } else {
        val--;
        printf("%d", val);
        wait(NULL);
    }
    val++;
    printf("%d", val);
    return 0;
}
```

如果 fork() 之后主程序先运行，则结果如何？如果 fork() 之后 child 先运行，则结果如何？

`fork` 前 `printf("%d", 0)` 只执行一次，输出 `0`。`fork` 后父子各自独立执行：

- **父进程先运行**：父 `val--=1` 打印 `1`，随后 `wait` 阻塞；子 `val++=3` 打印 `3`，继续 `val++=4` 打印 `4` 后退出；父 `wait` 返回，`val++=2` 打印 `2`。输出：**`01342`**
- **子进程先运行**：子 `val++=3` 打印 `3`，继续 `val++=4` 打印 `4` 后退出；父 `val--=1` 打印 `1`，`wait` 立即返回，`val++=2` 打印 `2`。输出：**`03412`**

3. 请阅读下列代码，分析程序的输出 A 的数量：( 已知 && 的优先级比 || 高)

```c
int main() {
    fork() && fork() && fork() || fork() && fork() || fork() && fork();
    printf("A");
    return 0;
}
```

按优先级加括号：`(fork()&&fork()&&fork()) || (fork()&&fork()) || (fork()&&fork())`，利用 `fork` 返回值（父>0、子=0）和短路规则逐层分析：

- **第一组 `f1&&f2&&f3`**：生成 3 个子进程（f1=0 的 C1、f2=0 的 C2、f3=0 的 C3）；父进程 P0 得到真值，`||` 短路，直接打印 A（**1 个 A**）；C1、C2、C3 第一组为 0，继续求值第二组。
- **第二组 `f4&&f5`**（C1、C2、C3 各自执行）：每个进程 fork 两次，父得真值打印 A（**3 个 A**）；f4=0 的子进程和 f5=0 的子进程（共 6 个）第二组为 0，继续求值第三组。
- **第三组 `f6&&f7`**（6 个进程各自执行）：每个进程 fork 两次，产生 3 个打印 A 的进程（f6=0 的子直接打印、f7=0 的子打印、父打印），共 **18 个 A**。

合计：1 + 3 + 18 = **22 个 A**。
